Projects

Odin Recipes

A simple HTML-only project that showcases three delicious recipes: sponge cake, noodles, and pizza. Each recipe has its own structured page with a list of ingredients and step-by-step instructions. This project demonstrates the use of semantic HTML elements and clean organization, serving as a beginner-friendly static site.

View Project

Janken (Rock, Paper, Scissors) Game

A simple interactive Rock, Paper, Scissors game built with HTML, CSS, and JavaScript. Players can select their move, and the computer randomly chooses its own. The game tracks scores and displays the winner after each round. It was a fun project to solidify my understanding of conditionals, events, and game logic.

View Project

Image Carousel Slider

A responsive image carousel built with HTML, CSS, and JavaScript. It includes navigation buttons and automatic sliding functionality to showcase multiple images in a seamless loop.

About Me

Hi, I’m a creative thinker, storyteller, and evolving techie who’s not afraid to explore new paths.
